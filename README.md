# PRIME-Ring: certificate-gated release for attribute-based ring anonymity

This repository contains the code and data for the PRIME-Ring evaluation. One command regenerates the synthetic data, checks the certificate implementation and writes every table as a LaTeX file and the figure as a PDF.

## Quick start

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
./run_all.sh                    # about 12 minutes on 2 vCPUs
```

To check the setup first, run a reduced version (about 2 minutes). Its numbers are noisier than the full run:

```bash
python3 reproduce.py --config config/quick.json --out results_quick
```

The code was tested with Python 3.13 on Linux. All randomness is seeded in `config/default.json`. Timing columns depend on the machine. All other values are deterministic for a given platform and library version.

## Data

All data are synthetic.

- **E-health.** `prime_ring_ehealth_access_log.csv` has 45,000 access events by 220 staff over 12 epochs. Each event has staff attributes, a policy handle, a plan identifier and an epoch status digest. `prime_ring_ehealth_staff_graph_edges.csv` gives the staff interaction graph per epoch.
- **OSN-Facebook and OSN-Twitter.** These are generated by `scripts/make_synth_osn.py`.
  - The graphs are dense communities joined by degree-preferential links. They are sized like SNAP ego-Facebook (4,039 nodes) and a scaled ego-Twitter (8,000 nodes).
  - Each graph has 10 attribute buckets with Zipf-skewed sizes, and 30% of users copy a neighbour's bucket.
  - Each user also has a region.
  - Moderation logs hold 5,000 and 50,000 events. The policy mix depends on the signer's bucket.
- **Policies.** `policy_registry.json` lists the registered policies of each domain and the attribute fields each one constrains. The "policy mask" target is that field set.

## What is implemented

- **Algorithms 1, 2 and 4** follow the paper. `tests/test_certificate.py` checks on a small graph that `certify()` equals the true Bayes posterior over every ring the sampler can produce.
- **The signature of knowledge** is a prototype for ring membership only. It is an SIS-based Σ-protocol with Fiat–Shamir with aborts, CDS OR-composition and 8 parallel 16-bit challenges, with parameters 256 × 512 and q = 8380417.
  - The credential, policy and opening-handle conjuncts of R_PRIME are not proved inside it.
  - Each transcript carries a real issuer certificate (the same primitive with a ring of size 1), a nonce, the epoch status digest and the plan identifier, all bound into the signed context.
  - Parameters measure cost and carry no security claim.
- **Keys.** Each user has an independent key pair per epoch. The verifier checks freshness, the nonce, plan length, snapshot membership of every ring key, and the proof, in that order. It then pads its running time to the plan cost Θ.
- **The opening handle** encrypts a hash of the signer's epoch key.
  - Encryption uses matrix LWE (dimension 256, q = 3329) made deterministic with the Fujisaki–Okamoto transform.
  - The opening proof is the encryption seed, which `JudgeOpen` re-encrypts to check.
  - Opening requires an authorisation record. Every opening is appended to a hash-chained log.
  - These parameters test correctness only.
- **Attack search** runs a fixed set of heuristic proposals (degree and bucket-size guesses) through a Monte Carlo checker on rings from the same sampler.
- **AOV attackers** are logistic regression, gradient-boosted trees and an MLP. They use epoch splits and five seeds. The table reports the best attacker, with chance equal to the majority label of the training split. `summary.md` also reports a variant that adds ring membership as features, and the positive control.
- **No-shape ablation.** When PadShape is removed, transcript length follows the policy circuit size. This is modelled as the number of distinct attribute tuples each policy grants in the log.

Comparisons with other schemes beyond BBS+ selective disclosure are made at the feature level (Table 1 of the paper). Their native costs are not measured here.
